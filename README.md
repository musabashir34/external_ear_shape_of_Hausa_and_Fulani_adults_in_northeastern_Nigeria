# Ear shape of Hausa and Fulani adults: reproducible article

This repository holds the raw landmark data and the R Markdown source of the article

> *Sexual dimorphism, ethnic variation and bilateral asymmetry in external ear shape of Hausa and Fulani adults in northeastern Nigeria: a geometric morphometric study*

Knitting `manuscript.Rmd` starts from the raw tpsDig2 files and produces:

- the article itself, as `manuscript.docx`: every number in the text, every table, the figures and the reference list are generated by the code;
- the six figures, in `output/figures/` as PDF (vector), TIFF (600 dpi, for submission) and PNG;
- Additional file 1 (Tables S1–S10), in `output/` as `Additional_file_1.docx` (formatted, with notes), `Additional_file_1.xlsx` and CSV files.

```
  01_functions.R            landmark configuration, conversion of tpsDig2 curves, statistics, plotting helpers
  02_prepare.R              raw tpsDig2 files -> 48-point configurations -> joint sliding of both sides
  03_analysis.R             all analyses (PCA, Procrustes ANOVA, CVA/DFA, asymmetry, measurement error)
  04_figures.R              Figures 1-6
  05_additional_file.R      Additional file 1
data/
  participants.csv          Individual, Sex, Ethnicity, Age (years) of the 400 participants
  raw/
    right_ears_raw.TPS      tpsDig2 file of the 400 right ears (11 landmarks + 7 curves per ear)
    left_ears_raw.TPS       tpsDig2 file of the 400 left ears (unmirrored images)

```

### Identifiers

`FFRE_004` = **F**emale, **F**ulani, **R**ight **E**ar, participant 004. Groups: FF Fulani female, FH Hausa female,
MF Fulani male, MH Hausa male. Specimen IDs are taken from the image names in the tpsDig2 files (`FFRE 004.jpg` →
`FFRE_004`), after the corrections listed in `data/raw/image_renames.csv`.

## Reproducing the article

Requirements: R ≥ 4.3 with `geomorph` (4.1.1 used), `RRPP`, `Morpho`, `MASS`, `abind`, `flextable`, `officer`,
`openxlsx`, `rmarkdown` and `knitr`.

```r
install.packages(c("geomorph", "RRPP", "Morpho", "abind", "flextable", "officer", "openxlsx", "rmarkdown"))
rmarkdown::render("manuscript.Rmd")
```

With 9999 permutations for every test, the first run takes about 10–15 minutes. The analysis chunk is cached, so later
runs that change only the text take seconds. For a quick check, use fewer permutations:

```r
rmarkdown::render("manuscript.Rmd", params = list(iter = 99))
```

The article shows each figure, with its title and legend, after the paragraph that first cites it. For the journal's
text-only version (figure titles and legends collected at the end;
the figures are uploaded separately from `output/figures/`):

```r
rmarkdown::render("manuscript.Rmd", params = list(embed_figures = FALSE))
```

The analysis stops with an explanation if the raw data are inconsistent, for example:

- an ear whose curve cannot be matched to its landmarks;
- a duplicated specimen ID;
- a participant without both ears.
